### ssh 反向隧道代理
	- > **让一台无法直接上网/无法访问外网的远程服务器（10.175.94.211），借用你本地网络里那个需要 Digest 认证的 HTTP 代理（10.191.131.45:3128）的出口，去访问外部网站（如百度）。**
	- ```bash
	  # 本机执行（可使用代理上网），10.175.94.211为目标机器，不能访问外网
	  ssh -f -N -R 127.0.0.1:13128:10.191.131.45:3128 root@10.175.94.211
	  # 目标机器通过隧道实现访问外网
	  curl --proxy http://127.0.0.1:13128 --proxy-digest --proxy-user USER https://www.baidu.com
	  # 关闭隧道
	  ps -ef | grep 'ssh.*13128' | grep -v grep | awk '{print $2}' | xargs kill
	  ```
